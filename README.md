#Pokemon Dashboard

1 — Project Title / Headline:

🎮 Pokémon Universe: Types, Stats & Generation Explorer Dashboard:-

An interactive and visually rich Power BI dashboard built to explore Pokémon data — focusing on type distribution, base stats analysis, generation breakdown, legendary Pokémon count, habitat comparison, and top Pokémon highlights.

2 — Short Description / Purpose:

The Pokémon Dashboard is a visually themed and analytically powerful Power BI report designed to help users explore the entire Pokémon universe through data. Built on a dataset covering hundreds of Pokémon across all generations, types, and habitats — this dashboard highlights key metrics like total Pokémon count, total types, legendary count, and total generations. This tool is built for Pokémon fans, data enthusiasts, and Power BI learners who want to understand which types are most common, how Pokémon are spread across generations, and which ones have the highest base stats.

3 — Tech Stack:

* 📊 Power BI Desktop – Main platform used for building all visuals and reports
* 🗂️ Power Query – Used for cleaning and transforming the raw Pokémon dataset
* 🧮 DAX (Data Analysis Expressions) – Used for KPI cards and custom measures like Total Pokémon, Total Types, Legendary Count, Total Generations, Pokémon Rank, and Top 3 Filter
* 📅 Data Modeling – Slicers set up for dynamic cross-filtering across all visuals
* 📁 File Format – .pbit for Power BI template
* 🎨 Theme – Pokémon inspired vibrant theme for an engaging visual experience

4 — Data Source:

Source:- https://www.kaggle.com/datasets/patelris/pokemon-dataset-with-stats-and-types

Dataset contains Pokémon records covering hundreds of unique Pokémon across all generations, types, and habitats — including stats, abilities, legendary status, and sprite image URLs.

Key Fields:

* Name – Name of the Pokémon
* Type_1 / Type_2 – Primary and secondary type (Fire, Water, Grass, etc.)
* HP, Attack, Defense, Sp_Attack, Sp_Defense, Speed – Individual battle stats
* Base_Stat_Total – Total combined stat score for ranking
* Generation – Which generation the Pokémon belongs to (1–8+)
* Legendary_Status – Whether the Pokémon is Legendary, Mythical, Baby, or Non-Legendary
* Habitat – Natural habitat of the Pokémon
* Abilities / Hidden_Ability – Pokémon abilities
* Sprite_URL – Image URL for each Pokémon


5 — Features / Highlights:

a — Business Problem:

The Pokémon universe spans hundreds of unique creatures across multiple generations, types, and stat categories. Without a structured analytical view, it becomes very difficult to understand which types dominate, how stats are distributed across habitats, and which Pokémon are truly the strongest. Fans, game designers, and data analysts both need a clear and simple way to explore this massive dataset.

b — Goal of the Dashboard:

The goal of this Pokémon Dashboard is to provide one single interactive report where anyone can:

* ✅ See Total Pokémon, Total Types, Legendary Count, and Generations using KPI Cards
* ✅ Understand type distribution using Pokémon by Type Donut Chart
* ✅ Track how Pokémon are spread across generations using Clustered Bar Chart
* ✅ Compare average stats across all types using Average Base Stat by Type Column Chart
* ✅ Discover habitat-wise stat differences using Avg. Stats by Habitat Bar Chart
* ✅ Explore top Pokémon using Top 3 Highest Base Stat Pokémon Table
* ✅ Filter the entire dashboard by Generation, Type, and Legendary Status using Interactive Slicers

c — Walk Through of Key Visuals:

* KPI Cards (Top Row): Show Total Pokémon, Total Types, Legendary Pokémon count, and Total Generations — gives an instant snapshot of the entire Pokémon universe in one glance.
  
* Pokémon by Type (Donut Chart): Shows how all Pokémon are distributed across primary types — clearly highlighting which types like Water, Normal, and Grass dominate the Pokémon world.
  
* Pokémon by Generation (Clustered Bar Chart): Displays how many Pokémon were introduced in each generation — helping understand which generation added the most new Pokémon.
  
* Average Base Stat by Type (Clustered Column Chart): Shows the average combined stat power for each Pokémon type — clearly showing which types like Dragon and Psychic have the strongest Pokémon on average.
  
* Avg. Stats by Habitat (Clustered Bar Chart): Compares average battle stats across different habitats — giving insight into whether habitat affects a Pokémon's overall power level.
  
* Top 3 Highest Base Stat Pokémon (Table): Displays the top 3 most powerful Pokémon ranked by Base Stat Total — giving a quick view of the absolute strongest Pokémon in the dataset.
  
* Interactive Slicers (3 Filters): Allow users to filter the entire dashboard by Generation, Type, and Legendary Status — with just one click enabling dynamic cross-filtering across all visuals.
  
d — Business Impact & Insights:

* 🌊 Water type dominates — leading as the most common primary type across all generations
* ⚔️ Dragon type Pokémon have the highest average base stats — making them the strongest type overall
* 🏆 Legendary and Mythical Pokémon stand out — with significantly higher stats than regular Pokémon
* 📈 Generation 1 and 5 introduced the most Pokémon — showing the biggest expansions of the Pokédex
* 🌿 Habitat affects stat power — Pokémon from mountain and rare habitats tend to be stronger
* 🔢 Data spans 8+ generations — covering classic starters to the latest legendary discoveries
